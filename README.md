# LOSTIQ

## Autonomous Multi-Agent Lost and Found Recovery System

LOSTIQ is an AI-powered Lost and Found system that autonomously investigates lost-item cases and identifies possible matches.

## Features

- Lost item reporting
- Found item reporting
- AI-powered investigation
- Found-item search
- Intelligent match scoring
- Geographical distance calculation
- User notification
- Ownership verification
- Case memory
- FastAPI backend
- Web frontend
- OpenRouter LLM integration
- GitHub Actions CI

## Technology Stack

- Python
- FastAPI
- SQLite
- OpenRouter
- OpenAI Python SDK
- HTML
- CSS
- JavaScript
- GitHub Actions

## AI Workflow

User → FastAPI → LOSTIQ Agent → Search → Matching → Location Check → Notification → Ownership Verification → Case Memory
